# WebApplication

Учебный веб-сервер на Go: отдаёт HTML-страницы на вёрстке Bootstrap и статические файлы.
Внешних зависимостей нет — только стандартная библиотека.

## Требования

- **Go 1.22 или новее.** Версия принципиальна: маршруты используют шаблон `/{$}`,
  который появился в `net/http` только в 1.22.
- Интернет при открытии страницы — CSS Bootstrap подключается с CDN.

## Структура

```
.
├── main.go                 # маршруты, раздача статики, запуск сервера
├── handlers.go             # вспомогательные хендлеры
├── db.go                   # модель User
├── go.mod
├── Images/
│   └── Logos/
│       └── PolitechLogo.png
└── Pages/
    └── HTML/
        ├── DisciplinesPage.html
        └── Bootstrap/
            └── MainPage.html
```

Всё в одном пакете `main`: файлы внутри пакета видят друг друга без импортов,
поэтому разбиение чисто для читаемости.

## Запуск

```bash
go run .
```

Сервер поднимется на `http://localhost:8080`.

Запускать нужно **из корня проекта**: пути к шаблонам и картинкам заданы относительно
рабочей директории процесса, а не расположения исходников.

## Маршруты

| Метод | Путь            | Что отдаёт                          |
|-------|-----------------|-------------------------------------|
| GET   | `/`             | `MainPage.html` — страница входа     |
| GET   | `/contacts/`    | заглушка, текст `bbb`                |
| GET   | `/disciplines/` | заглушка, текст `ccc`                |
| GET   | `/Images/...`   | файлы из папки `Images/`             |

## Как устроено

**Шаблон парсится один раз при старте** через `template.Must` в глобальной переменной.
Если файл не найден, программа падает сразу с понятной ошибкой — а не паникует
на первом запросе с трейсом про nil pointer.

**Статика раздаётся `http.FileServer`** с `http.StripPrefix`: запрос
`/Images/Logos/PolitechLogo.png` превращается в чтение файла `Images/Logos/PolitechLogo.png`.
Без этого обработчика картинки возвращали бы HTML вместо изображения.

**Корень зарегистрирован как `/{$}`, а не `/`.** Шаблон `/` в `net/http` работает как
catch-all и перехватывает вообще все необслуженные пути — из-за этого запрос
несуществующего файла отдавал бы HTML со статусом `200` вместо честного `404`.
`{$}` ограничивает совпадение точным корнем.

**Bootstrap подключается с CDN** в `<head>` страницы, стили формы лежат в `<style>`
прямо в HTML. Локальных CSS-файлов в проекте нет.

## Заметки

Пути к статике в HTML пишите с ведущим слэшем — `/Images/...`, а не `Images/...`.
Без него браузер считает путь относительно текущего URL, и та же страница,
открытая по адресу `/contacts/`, будет искать картинку в `/contacts/Images/...`.
